# Kataleya — standalone PWA (historical copy)

**This repository is not the maintained source for the current Kataleya release.** It is a
standalone PWA implementation retained for its history. Its code and release claims are not
kept in sync with the current product.

## Current product

- **Use the web app:** <https://kontor.studio/kataleya-demo/>
- **Maintained web source:** [`kontor-studio/kataleya-demo/`](https://github.com/kwasikontor45/kontor-studio/tree/main/kataleya-demo)
- **Product resources and release guidance:** <https://kontor.studio/kataleya-resources.html>
- **Android wrapper configuration:** [`kataleya-android`](https://github.com/kwasikontor45/kataleya-android)
- **Planned native app scaffold:** [`kataleya-mobile`](https://github.com/kwasikontor45/kataleya-mobile)

The web source is maintained in `kontor-studio`; update that source first. This archive may be
used for historical comparison, but do not deploy it or present it as the current release without
independently reviewing and validating it.

## About this archive

This repository contains an older standalone HTML, CSS, and JavaScript PWA, its service worker,
icons, a vendored cryptography bundle, and an optional relay-worker directory. No current release,
security audit, clinical validation, backend availability, or compatibility claim is made for
those components here. Review the source and its license notices before reuse.

Kataleya is a personal wellbeing companion, not medical, clinical, or crisis-care software. It is
not a replacement for professional support or emergency services.
